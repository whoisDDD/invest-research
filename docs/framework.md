# 投资研究框架

本框架给研究规定问题与证据，不预设每家公司都应得到相同评级。日常更新只写新增事实及其影响，首次覆盖才做完整分析。

## 1. 研究对象与原始命题

确定对象是市场、行业、公司还是组合。记录截至时间、持有或观察周期、已有假设、最关心的问题和可推翻条件。观察名单由用户决定，技术示例不是荐股名单。

产物：一句话研究命题、范围、3个决定性变量。

## 2. 宏观与市场

研究利率、汇率、信用与流动性如何影响对象的融资成本、需求或估值。把机制写清楚，不用宏观新闻堆砌解释所有股价。

市场估值用同口径历史序列，同时看利润增长、行业结构、利率背景及集中度。历史百分位是相对位置，不直接等于内在价值。

产物：影响对象的2—3条传导路径及对应数据。

## 3. 行业与竞争

辨认价值链、需求驱动、供给/产能、价格、库存、客户资本开支、替代技术、政策与竞争格局。区分周期回升、份额提升和结构成长。

同行选取须说明业务可比性。相同数据经不同MCP返回不算独立来源。

产物：行业关键变量、同行比较、景气判断的证据与反证。

## 4. 公司与商业模式

谁付钱、为什么持续付钱、成本由什么决定、增长由什么驱动、资本投入有多大。拆解产品/地区/客户、量价、竞争优势、客户集中和管理层资源分配。

产物：收入和利润驱动树。拆不出量价时明确资料缺口，不编造拆分。

## 5. 财务与质量

经营：营收、归母与扣非利润、单季、TTM、同比。
盈利：毛利率、净利率、ROIC/ROE及其定义。
现金：CFO与利润、应收/存货/合同资产、营运资金。
再投资：资本开支、研发资本化、收购、现金回报。
资产负债：现金、债务、到期结构、利息与表外承诺。
会计：一次性损益、补助、减值、税率、重述、审计事项、关联交易。

先描述变化，再查驱动，最后判断是否持续。一次性增长不能直接外推；营收不能代替净利润。

## 6. 行业专用模块

- 银行：净息差、贷款与存款、资产质量、拨备、资本充足与ROE/PB；不套普通企业FCF。
- 保险：负债成本、投资收益、偿付能力及相应价值指标，注明准则。
- 周期制造：价格/销量/库存/产能/资本开支，观察完整周期盈利。
- 平台与软件：收入结构、付费/留存、单位经济、股权激励和稀释。
- AI与算力：训练/推理/云服务业务区分；收入、资本开支、折旧、能源、融资租赁、购买承诺、利用率与现金流分别核实。业务KPI不一定在标准财报接口中存在。
- 房地产/工程：回款、合同资产、预收/合同负债、减值、负债期限与现金受限。

按研究对象选有关模块，不机械填满所有项目。

## 7. 估值、预期与情景

先选择适合商业模式的估值方法。可以使用PE/PB、EV相关倍数、现金流情景或分部估值，但分母、权益/企业价值、净债务与币种必须一致。

至少区分三组假设：保守、基准、较乐观。每组展示收入、利润率、再投资、资本结构和估值输入中真正影响结论的变量。没有证据不分配上涨概率，不给伪精确小数目标价。

将“经营值得看好”与“当前价格值得买入”分别讨论。估值模型必须可算回输入；对敏感参数做变化分析。

产物：情景表、敏感性、市场已反映的预期、判断失效条件。

## 8. 风险、事件与人工判断

按影响和证据排序：经营、财务、治理、政策、技术替代与估值风险。每项说明触发信号、可观察指标与可能影响。事件催化不保证价格上涨。

最终形成：
- 已确认事实；
- 最可信的解释；
- 当前最关键不确定因素；
- 分析者观点及其依据；
- 用户必须自己判断的事项。

允许有鲜明结论，不靠冗长免责声明或机械正反列举稀释重点。

## 9. 跟踪与复盘

每次更新对照上次命题，问“什么新事实会改变原判断”。记录预测与后续实际经营表现，区分研究错误、估值变化和不可预知事件。

日期触发和事实触发可以同时使用；本仓库不会默认创建提醒、推送或交易动作。

## 报告结构

1. 一屏摘要：发生了什么、为什么重要、观点。
2. 证据与关键图表：增长、质量、再投资、资产负债、估值。
3. 行业/公司解释与同行对照。
4. 情景、预期差与失效条件。
5. 人工判断记录、后续观察指标。
6. 来源和影响结论的数据缺口。

每个关键数字关联metric_id或source_id；每张图说明单位、期间、币种、来源和截至时间。指数换成分、财报重述和多币种差异必须说明。
