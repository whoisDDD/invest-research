# 财报看板

## 当前体验

默认report.html以图表为主。六张卡片展示营收、归母利润、经营现金流、资本开支、TTM归母净利率和TTM自由现金流。四组图表分别看收入利润趋势、同口径同比、现金投入与利润、TTM净利率；不是把表格数值重复铺满页面。

可以切换公司/币种、截至报告期、4期/8期/全部历史、TTM/单季/累计；图例可开关。卡片、数据点和明细数值都能打开证据面板，查看完整精度、缺失期间、计算所需事实和来源链接。明细支持搜索、排序与CSV导出；另有深浅主题及窄屏布局。

## 指标与证据规则

- 浏览器只筛选、格式化、排序和绘图，不重新定义财务公式。金额和比率取自Python metrics.json，导出保留原始字符串精度。
- 不混合不同币种；横轴使用真实时间间隔，缺少单季或TTM值会留空和断线。纵轴包含零，负值正常显示。
- 利润、营收和CFO采用所选口径；净利率、自由现金流卡片明确标注固定TTM。资本开支不完整时不补造FCF。
- 来源面板按每项指标的fact_refs展示，不把一条已核对事实扩大为整项派生指标全部核实。
- 本期观察仅列已算出的变化，不自动解释原因，也不冒充AI投研结论。分析仍由Agent结合原始披露、framework.md和人工判断完成。
- 生成HTML自包含，无CDN、远程脚本、埋点或联网取数。静态报告和脱库复算研究包保留。

## 演示

CLI demo采用examples/dashboard-demo.csv：两家虚构公司，各19个季度，152条累计流量事实；全部明确标注SYNTHETIC与示例来源。此演示用来体验交互，不作为任何真实证券数据。旧examples/demo.csv保留为最小回归样例。

## 对标汇总视频的后续扩展

现有契约只有公司、日期、币种及四个流量字段。行业热力图、全市场排名、分位数或指数汇总不能靠这份输入直接生成。后续先补以下数据，再加相应页面：

| 场景 | 需要的数据 |
| --- | --- |
| 行业/市场热力图 | 完整样本池、行业分类及版本、成分与截至时间、可比财务口径 |
| 同行比较 | 多家公司同一期间/币种/准则的输入及缺失说明 |
| 估值与预期差 | 有日期的股价、市值、股本/分红和对应盈利口径 |
| 情景推演 | 可编辑但明确标注的假设、独立计算结果、与披露事实分开 |

当前版本先把已有证据变得易读、可探索；不会展示没有对应数据的市场地图、评级或盈利预测。
