# 跨Agent使用

## OpenCode / DSH / WorkBuddy

1. 从Drive下载ZIP并解压，或从GitHub clone项目，放到本地独立目录并打开。Drive交付见docs/drive-quickstart.md。
2. 首轮让Agent读AGENTS.md，运行doctor、测试和demo。
3. 按docs/providers.md从官方来源安装/授权相应工具；不复制其他人的登录状态。
4. 官方Skill按该客户端当前支持的位置加载，厂商MCP按该客户端schema配置；不把同一份客户端JSON不加修改地复制给所有产品。
5. 用一家公司验证实际工具、返回和日期，再把数据映射为facts.csv。
6. 调用已有程序生成报告。新接数据源时先交付原始证据与字段映射，不先写结论。
7. 确认真实数据结果后，扩大自选池。

AGENTS.md是共享规则文件；若客户端不自动加载，明确要求本次任务先读取。fork不会自动安装工具、配置账号或获得数据权限。

## ChatGPT

可以直接使用账号已有的相应数据连接器；如无匹配项，按当前产品入口评估自定义MCP，或读取review_pack。哪个入口方便就用哪个，统一指标口径。

首次研究用prompts/research.md；交叉检查用prompts/review.md。
在可执行Python的会话中解包并复算；若当前产品/工具不支持运行代码，说明只完成阅读核对，不声称已复算。

研究包附本次计算脚本、输入数据、指标、口径、来源、质检和哈希。当前本版不嵌入模型API，不要求另买模型服务。

## 本地与云端界限

本地stdio服务和CLI在本地电脑运行。云端会话不能默认访问该电脑的localhost或工作目录。可使用受支持的官方远程服务；自建跨环境连接先确认产品支持和授权，不默认公开本地服务。

账号信息、私人持仓、密钥和供应商批量数据不随Git仓库共享。需要讨论时只导出本次所需的研究快照。

## 操作示例

“读取AGENTS.md，使用我已经授权的腾讯自选股或iFinD工具，研究指定公司最近财报。先验证数据和指标，按docs/framework.md输出事实、解释、情景和人工待判断事项。将证据保存在本地，并生成研究包。”

定时更新待手动连续验收后再加，且只选一个调度器。初次不自动建立通知、模拟交易或券商连接。
